Pour s'exercer. Tentatives libres, aide et solution selon vos réglages.

Notée

Pour évaluer. Dates obligatoires, durée limitée ; les enseignants du cours corrigent.

Pour se mesurer. Un classement dans l'onglet Challenges. Ce choix est définitif.

Sécurité de l'épreuve

Plein écran obligatoire, arrêt si l'étudiant quitte la page ou la fenêtre ; code de reprise créé.

Plein écran obligatoireL'épreuve s'ouvre en plein écran ; en sortir l'arrête.

Arrêter l'épreuve si l'étudiant quitte la pageOnglet changé, page fermée ou rechargée.

Arrêter l'épreuve si l'étudiant quitte la fenêtreIl passe à une autre fenêtre ou à une autre application.

Bloquer le copier-coller

Il rouvre une épreuve arrêtée tant que son temps n'est pas écoulé ; le temps continue de courir pendant l'arrêt. Vous le donnez en salle à l'étudiant concerné. Il ne sert pas à commencer, et un nouveau code rend l'ancien inutilisable.
