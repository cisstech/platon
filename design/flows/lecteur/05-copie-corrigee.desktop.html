Exercice 2, Année bissextile, réussi en partie, 80 sur 100

Écrivez une fonction bissextile(annee) qui renvoie True si l'année est bissextile, False sinon.

Votre réponsedef bissextile(annee): if annee % 400 == 0: return True return annee % 4 == 0

4 tests sur 5 réussis. Échoue : bissextile(1900) renvoie True, attendu False.

Il manque la règle des siècles : une année divisible par 100 n'est pas bissextile, sauf si elle l'est aussi par 400. Ajoutez ce cas entre vos deux tests.

Exercice 3, Maximum de trois nombres, réussi, 100 sur 100

Écrivez une fonction documentée maximum(a, b, c) qui renvoie le plus grand des trois nombres, sans utiliser max.

Votre réponsedef maximum(a, b, c): m = a if b > m: m = b if c > m: m = c return m

19 tests sur 20 réussis. Échoue : la fonction n'a pas de docstring.

Très clair : une variable garde le plus grand nombre vu jusqu'ici. C'est déjà l'algorithme du maximum d'un tableau, que vous retrouverez au TP 4.

Note de l'exercice : 95 aux tests, +5 pour l'étiquette « Solution élégante », soit 100 / 100.

Exercice 4, Tarif selon l'âge, réussi, 100 sur 100

Écrivez une fonction tarif(age) : gratuit avant 4 ans, 5 € jusqu'à 17 ans inclus, 9 € ensuite.

Votre réponsedef tarif(age): if age < 4: return 0 elif age <= 17: return 5 return 9

Exercice 5, Mention au baccalauréat, réussi en partie, 60 sur 100

Écrivez une fonction mention(note) qui renvoie la mention d'une note sur 20 : « Très bien » à partir de 16, « Bien » à partir de 14, « Assez bien » à partir de 12.

Votre réponsedef mention(note): if note >= 12: return "Assez bien" elif note >= 14: return "Bien" elif note >= 16: return "Très bien" return "Sans mention"

3 tests sur 5 réussis. Échouent : mention(15) renvoie "Assez bien", attendu "Bien" ; mention(17) renvoie "Assez bien", attendu "Très bien".

L'ordre des conditions compte : dès que note >= 12 est vrai, les branches suivantes ne sont jamais lues. Commencez par la mention la plus haute.

Exercice 6, Jour de la semaine, réussi, 100 sur 100

Écrivez une fonction jour(n) qui renvoie le nom du jour, de 1 pour lundi à 7 pour dimanche, et None sinon.

Votre réponsedef jour(n): noms = ["lundi", "mardi", "mercredi", "jeudi", "vendredi", "samedi", "dimanche"] if 1 <= n <= 7: return noms[n - 1] return None

8 tests sur 8 réussis.

734/ 100

Exercice 7, Équation du second degré, réussi en partie, 34 sur 100

Écrivez une fonction racines(a, b, c) qui renvoie le nombre de solutions réelles de ax² + bx + c = 0, avec a non nul.

Votre réponsedef racines(a, b, c): x = b ** 2 - 4 * a * c if x >= 0: return 2 return 0

9 tests sur 25 réussis. Échouent : les 16 cas où le discriminant est nul, par exemple racines(1, 2, 1) renvoie 2, attendu 1.

Un discriminant nul donne une racine double, donc une seule solution : x >= 0 mélange deux cas. Testez x == 0 à part.

Appelez cette variable delta : x se lit comme l'inconnue de l'équation.

Note de l'exercice : 36 aux tests, -2 pour l'étiquette « Nommage peu clair », soit 34 / 100.
