Question 6 : Pour quelles valeurs de p et q la fonction f renvoie-t-elle False ?, réponse enregistrée

On considère la fonction suivante. Plusieurs réponses sont possibles.

def f(p, q): return (not p or q) and (p or not q)
p vaut True, q vaut True
p vaut True, q vaut False
p vaut False, q vaut True
p vaut False, q vaut False
