Exercice 3 sur 6 : boucles imbriquées. Ferme ce soir à 23 h 59.

3.1

Question 3.1 : Combien de fois la ligne c = c + 1 s'exécute-t-elle pour compte(4) ?, juste

On considère la fonction suivante.

def compte(n): c = 0 for i in range(n): for j in range(i): c = c + 1 return c
6

Juste. i vaut 0, 1, 2 puis 3 : la boucle intérieure tourne 0 + 1 + 2 + 3 = 6 fois.

3.2

Question 3.2 : Quelle est la complexité de compte(n) ?, faux

O(n)Votre réponse
O(n log n)
O(n²)Bonne réponse
O(n³)

Faux. La boucle intérieure tourne i fois pour chaque i : 0 + 1 + ... + (n - 1) = n(n - 1) / 2 passages, un nombre qui croît comme n². Deux boucles imbriquées sur n donnent souvent du n².
